# Codebuddy 会话启动与记忆

> Codebuddy 低频角色专属。共享约束见 `001-general.md`（kernel 生成，勿手改）。

## 启动检查
1. 读 `.workbuddy/rules/001-general.md`（通用约束，kernel 生成）。
2. 读 `.workbuddy/memory/MEMORY.md`（长期记忆）+ 最近 1-2 篇日记（`2026-*.md`）。
3. 读 `docs/R&D/PENDING.md`（待决决策，若有；看"有 N 条结论待确认"）。
4. 按任务读 `004-project.md`（环境/测试）或 `009-doc-sync.md`（文档同步）。

## 记忆回流
- 会话产生新结论 / 约定时，提议更新 `memory/MEMORY.md` 或新增当日日记。
- 记忆结论要有落点：固化到 `MEMORY.md` / 日记，或标记待决到 `docs/R&D/PENDING.md`。
- 一次性任务无新约定则跳过。
