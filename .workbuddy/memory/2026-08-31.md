### 新查到的市场数据（与 8/22 存量分析口径不同，重要）
- Upwatcher 2026-05（3,597 条 Python 岗位）：**中位时薪 $30/hr、中位固定价 $170**；
  固定价 55.7% < $250，75 分位 $600，90 分位 $2,500，仅 79 单 > $5k。
- 真实订单样本：PDF→Excel $10 fixed（50+ proposals）、PDF Content Extraction $60 fixed、
  PDF Data Entry $10 fixed → 这些属「数据录入」类目，是 VA 的活，不是 AI 工程师的活。
- 存量文档用的报价锚（pilot $400-900 / 标准 $1.2-3.5k / 工作流 $2.5-6k）实际落在**前 10-25%**，
  不是主流分位。
- Freelancer 样本原话（关键）：客户要 "any script, macro or tool configuration you use, so I can
  refresh the file if new PDFs arrive… Python (tabula, camelot, pdfplumber) or VBA… replicate the
  environment on my side" → **客户点名要 camelot/pdfplumber，且要能自己重跑**。
- 客户恐惧点排序："flag unclear info instead of guessing" / "100% accurate" / 隐私
  （VA 外包的缺点被明确列为 privacy concerns）。
- 本地 AI 白皮书（HumanSpark, 128GB mini-PC）：本地化是**隐私叙事不是成本叙事**
  （"unlikely to cut costs at normal small-firm volumes"）。
- Python+AI 溢价 40-60%，但 Upwork 上 $100+/hr 仅占 3.3%。

### 提出的核心框架：三层市场 × 三种交付形态
| 层 | 价位 | 客户买什么 | DocuVision 形态 |
|---|---|---|---|
| L1 跑量 | $10-250 | 一个 xlsx | 后台工具，客户不知其存在 |
| L2 自动化 | $600-2.5k | 脚本+可复现环境+能自己重跑 | CLI / 单文件脚本 |
| L3 集成私有化 | $2.5k-7k | 系统+复核闭环+不出境 | 完整 Pro 平台（现状形态） |

**核心判断：当前仓库 100% 为 L3 设计，80% 的单子在 L1/L2。**

### 五条切片建议（要点）
1. `docuvision-core` 拆 `[table]`（pdfplumber/camelot/pandas/openpyxl/PyMuPDF，**零 torch** ~50MB）
   / `[ocr]`（+easyocr）/ `[vision]`（+torch，降级可选）。现状 `lite` extra 把 easyocr 与表格捆一起。
2. SDK 门面按**交付物**切而非按引擎切（推翻 8/23 的最小 4 函数 ocr/layout/fields/confidence_route
   作为门面）：`extract_tables()` / `extract_fields()` / `to_excel()` / `review_report()`。
   ocr()/extract_layout() 降为内部能力。
3. **存疑标记必须落到交付文件里**（Excel 一行 `⚠` 列 / review.csv），不是 Web UI 的 HITL 队列 —
   客户不会登录你的系统。这是对客户原话 "flag unclear instead of guessing" 的直接兑现。
4. table alias 从代码挪到 JSON vendor profile（比存量 P0-4 更狠：要能交给客户自维护，
   这是 L2 能否成立的关键）。
5. templates/ 三个 starter 骨架（pdf-to-excel / invoice-extract / scan-digitize），cp -r 不改 import。

### 对存量 P0 的反对意见（待用户确认）
- **反对 P0-1 可搜索 PDF 的最高优先级**：本次抽样未见对应真实需求，且有免费在线工具竞争、
  单价低。真正 P0 = alias JSON 化 + 存疑标记 + 合并 sheet（直接决定 L1/L2 交付成本）。
- **P2-1 Mail bridge 不建**：n8n / Power Automate + 现有 webhook 足够。
- 前端 SPA（Reviews/Batch/PDF Tools）**冻结不删除**：作为 L3 投标 Demo 资产保留，但不再投入。
- formula_service / seal_service 冻结（Upwork 无对应需求密度）。
