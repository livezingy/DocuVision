## Epic: Single-task result persistence

### Motive

v1.5 persisted Batch and HITL only (`batch_jobs` / `hitl_reviews`). v1.6 wrote figure crops to `OUTPUT_DIR/{task_id}/figures/` and packs them via `GET /tasks/{id}/export/zip`, but `main.py` still keeps `tasks: Dict[str, Dict[str, Any]]` in memory. After restart those routes **404** even when PNGs remain on disk.

Cited from current living copy:

- [KNOWN_LIMITATIONS.md](../release/KNOWN_LIMITATIONS.md) — «Single-task results»
- [v1.6-roadmap.md](./v1.6-roadmap.md) Adversarial — «Restart»
- [RELEASE_1.6_NOTES.md](../release/RELEASE_1.6_NOTES.md) out of scope — single-task `tasks` dict
- [queue_store.py](../../backend/app/services/persistence/queue_store.py) — two-table registry + WAL + `threading.Lock`; `CREATE TABLE IF NOT EXISTS`; no Alembic

### Scope (MVP)

Reuse v1.5 `QueueStore` + the same `docuvision.sqlite` (`SQLITE_DB_PATH`, WAL + Lock). **Add a third table.** No new middleware.

Suggested table name: `analyze_jobs` (avoid colliding with Batch `tasks` JSON column).

| Column | Type | Notes |
|--------|------|-------|
| `task_id` | TEXT PK | same id as `/tasks/{id}` |
| `status` | TEXT | persist completed / failed / interrupted |
| `file_name` | TEXT | original upload name |
| `file_path` | TEXT | path under `UPLOAD_DIR/{task_id}/` |
| `created_at` | TEXT | ISO |
| `completed_at` | TEXT | nullable |
| `options` | TEXT JSON | switches needed to re-serve export / figures |
| `result_path` | TEXT | pointer to `OUTPUT_DIR/{task_id}/result.json` — **do not store the full result in SQLite** |
| `quality` | TEXT JSON | optional list-page summary; no HTML / table bodies |

Behaviour:

1. When a task reaches `succeeded` / `completed`: write `result.json` on disk and upsert one `analyze_jobs` row.
2. On process start: `load_from_db()` rebuilds the in-memory `tasks` dict. Rows whose `result_path` or crop dir is missing become `missing_artifacts` (or equivalent); do **not** 500.
3. In-flight tasks after restart **do not auto-resume GPU**. Align with Batch (`processing → paused`, no auto GPU). Single-task has no resume API today — mark interrupted / failed; user re-submits.
4. Route semantics stay: `GET /tasks/{id}`, `/result`, `/export/*`, `/figures/*` still read `tasks`. Miss in memory → load from store (or hydrate at startup only; pick one and test it).
5. FIFO retention: keep the last N completed tasks (dedicated `TASK_KEEP_LAST_N`, default 50, same idea as `DEBUG_KEEP_LAST_N`). Evict DB row **and** `OUTPUT_DIR/{task_id}/` together.

Do not change `figure_step` contract or ZIP layout ([docuvision-system-design.md](./docuvision-system-design.md) §9.1).

### Out of scope

| Item | Why |
|------|-----|
| Auto-resume in-flight GPU jobs | Would burn GPU with no operator action; Batch already chose manual resume |
| Full result / page images / crops **inside SQLite** | Long PDFs blow a single-file DB (v1.5 already warned on JSON-column size) |
| Webhook persistence | v1.5 out of scope; unrelated to task restore |
| Lite ZIP / Batch multi-task ZIP / table-region screenshots | v1.6 written deferral |
| Searchable PDF / AcroForm / Mail bridge | [v1.5-roadmap.md](./v1.5-roadmap.md) leftovers; next trains |
| Redis / multi-replica | Still single-host SQLite |
| Recent-tasks UI | Nice-to-have; **not** a Cloud gate. API restore is the MVP |

### Acceptance

权威：`backend/tests/test_task_persistence.py`

- Local mock (no Paddle): `backend/tests/test_task_persistence.py` — write a completed task → clear the in-memory dict → `load_from_db` → `export/zip` and `figures/{id}` still 200 (temp dir, fake PNG + fake tables). Same isolation style as `test_queue_persistence.py` (do not import `app.main` if that pulls Paddle).
- Cloud **TASK-PERSIST-001**: analyze completes → kill `:8000` → start again → same `task_id` serves result + ZIP + at least one figure GET.

### Adversarial check

- **Disk present, DB gone** (operator changed `SQLITE_DB_PATH`): load is empty; ZIP still 404. Mitigation: log path mismatch; optional startup scan of `OUTPUT_DIR/*/` to re-register (not required for MVP).
- **DB present, crops FIFO-deleted**: result may load; figure/ZIP missing images. Mitigation: delete directory and DB row together; ZIP already allows missing figures without 500 (`figure_count: 0`).
- **Full `html_structure` / tables as a JSON column**: hundred-page upserts lock the DB. Breakpoint is «put result in SQLite». Must use a file pointer.
- **SPA only holds `currentTaskId` in this session**: backend restore does not help a refreshed tab that lost the id. MVP is API restore; Recent-tasks UI is optional and must not block the tag.
