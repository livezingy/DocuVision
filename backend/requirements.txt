# Pro GPU (Cloud Studio) — do NOT pip install torch from this file on GPU.
# Use the split stack below; keep Lite in a separate venv (requirements-lite).
#
#   python3 -m venv ~/docuvision_env && source ~/docuvision_env/bin/activate
#   cd backend
#   ./install_pro_gpu.sh
#
# Manual equivalent:
#   1. pip install -r requirements.txt
#   2. pip install -r requirements-gpu-torch.txt
#   3. pip install paddlepaddle-gpu==3.3.0 \
#        -i https://www.paddlepaddle.org.cn/packages/stable/cu129/
#   4. pip install paddleocr==3.3.2 "paddlex[ocr]==3.3.12"
#   5. pip install -r requirements-gpu-nvidia.txt
#   6. cp -n .env.cloud .env
#   7. source ./env_pro_gpu.sh && DEBUG_MODE=false python run.py   # optional; auto via venv hook + run.py
#
# Notes:
#   - paddlepaddle-gpu 3.3.0 GPU wheel is cu129-only on the official index.
#   - torch/torchvision use cu124 wheels (requirements-gpu-torch.txt); nvidia 12.9 re-pin
#     (requirements-gpu-nvidia.txt) avoids libnvJitLink / libcusparse conflicts.
#   - requirements-gpu-nvidia.txt includes nvidia-cusparselt-cu12 (libcusparseLt).
#   - LD_LIBRARY_PATH: auto on venv activate (install_pro_gpu.sh) and in run.py / pytest.
#   - Manual: source backend/env_pro_gpu.sh only if activate hook missing.
#   - KIE warmup: see .env.cloud (DOCUVISION_KIE_WARMUP=1).
#   - Cloud validation: docs/architecture/CLOUD_VALIDATION.md
# =============================================================================
